    What produced the view above

    Two stylesheets, one tag and an array. The element reads the clock off the media element it is bound to, drives its own frame loop while that clock runs, and sends a click on a line back to audio.currentTime.

    This page imports ../dist/package/element.js rather than the bare specifier below, because it loads the emitted artifact straight off disk with no bundler and no import map.

  import "@braccato/core/element";

  // Nothing here parses a lyrics format, so the array is yours to produce.
  document.querySelector("braccato-lyrics").lyrics = [
    {
      startTimeMs: 3000, durationMs: 3000, words: "The kettle starts at six",
      parts: [
        { startTimeMs: 3000, durationMs: 375, words: "The " },
        { startTimeMs: 3375, durationMs: 375, words: "ket" },
        { startTimeMs: 3750, durationMs: 375, words: "tle " },
      ],
    },
  ];
</script>

    The rest of the surface

    Properties you write

    lyrics
    A Lyric[]. Optional parts carry syllable timing; an empty array clears the view, and null means the element was never given a song.
    source
    A selector or a media element. While it is bound, currentTime and playing become outputs and a write to either is dropped.
    theme
    A compiled stylesheet. Its blyrics-* comments configure the module; the sheet itself goes into the document head.
    tickOptions
    The rest of a tick: user offsets, passive scrolling, and the timestamp of the snapshot the clock came from. Read by the next tick rather than causing one.
    renderer, mediaElement, status
    Read-only. status is the answer for a consumer who was not holding a listener.

    Events you get back

    braccato:lyrics-loaded
    { lineCount, syncType }. Fires when lyrics are applied, including the rebuild a theme change forces.
    braccato:line-click
    { timeS }. The seek has already reached the bound media element by the time it fires.
    braccato:scroll-state
    { userScrolling }. Autoscroll stopped following the song, or started again.
    braccato:error
    { phase, error }. Connecting, resolving a source, or applying lyrics or a theme went wrong. Dispatched a microtask late so a listener added right after insertion still hears it.

    All four bubble and are composed, so an element placed inside your own shadow root still reaches your listener.

    The song is synthesized by tooling/generate-demo-audio.ts from the same score the lyrics are built from, so a syllable cannot drift from the note it lands on.
